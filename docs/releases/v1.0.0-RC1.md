## Deploy (human-operated)

Do **not** auto-deploy from agents. After secrets verification:

```bash
git checkout main && git pull origin main
npm ci
npm run lint && npm run type-check && npm test && npm run build
npm run deploy:cf
# equivalent: npm run build && wrangler pages deploy dist --project-name=istebul-com
```

Confirm Cloudflare Pages env bindings and Supabase secrets before deploy.
