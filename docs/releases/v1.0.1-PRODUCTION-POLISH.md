# v1.0.1 — Production Polish Sprint 1 (EPIC-401)

**Release:** `v1.0.1` (Production Polish)  
**Date:** 2026-07-22  
**Scope:** Visual / UX polish only — no new features, no runtime behavior change, no database / API / auth / tenant changes.

## Summary

Post–v1.0.0 polish pass focused on the platform landing chrome: navbar, hero, product cards, shared button language, typography, accessibility focus treatment, and small CSS delivery cleanups.

## Fixed UI issues

### P1 — Navbar
- Equalized flex gap for **Kaynaklar** (dropdown) and **Partner başvurusu** vs adjacent controls
- Unified hover / focus styles (no underline drift; shared blue wash + focus ring)
- Mid-desktop padding tightened so the primary CTA stays on one line
- Mobile: Kaynaklar label spacing + Partner başvurusu hover match nav-link language
- Mobile: hide duplicate **Hakkımızda** entry when mobile resource links flatten via `display: contents`

### P2 — Hero
- Reduced top/bottom padding on `.ib-platform-hero` / landing variant
- Vertical centering via flex alignment on the hero shell
- Smaller empty-mount CLS reservation (mounted content still expands naturally)

### P3 — Platform cards (İSTEBUL AI · GarsonAI · İSTEBUL Business)
- Header / badge vertical alignment
- Title / description min-heights + line clamps for equal card rhythm
- Full-width CTA footers so CTAs share the same baseline across the three-column grid
- Mobile (&lt;480px) relaxes fixed min-heights

### P4 — Buttons
- Shared primary / outline-secondary / ghost hover + focus + disabled language (`button-states.css` + polish layer)
- Nav partner / ghost / primary CTAs use the same focus token

### P5 — Typography
- Heading line-heights and section title spacing on platform landing surfaces
- Muted body copy contrast set to `#475569`
- Responsive font clamps for hero brand/title on small viewports

### P6 — Accessibility
- Consistent `:focus-visible` rings on nav links, dropdown items, theme/user controls, and platform CTAs
- `aria-label` on Partner başvurusu nav control
- Status badge contrast tweak for “canlı”
- `prefers-reduced-motion` disables polish transitions

## Responsive improvements

- Desktop nav gaps + CTA nowrap
- Tablet (901–1180): compact nav/auth padding
- Mobile (≤1180): Kaynaklar mobile block spacing; Partner mobile link hover parity
- Card grid keeps equal visual weight from 1→2→3 columns

## Accessibility improvements

- Focus rings use a single `--ib-pp-focus` token (3px blue halo)
- Dropdown menuitems receive the same focus treatment as top-level nav
- Partner control exposes an explicit accessible name

## Performance notes (P7 — detect only / safe cleanups)
