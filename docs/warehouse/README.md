# WarehouseIQ

WarehouseIQ, İSTEBUL Platformu içerisinde geliştirilen yeni nesil
AI destekli Warehouse Operating System (WOS)'dur.

## Ana Modüller

- Depo Yönetimi
- Lokasyon Yönetimi
- Ürün Yönetimi
- Stok Hareketleri
- Mal Kabul
- Picking
- Packing
- Sevkiyat
- Lojistik
- Dashboard
- AI Copilot

Bu ürün ERP değildir.

Operasyon merkezli çalışan,
AI destekli depo ve lojistik işletim sistemidir.
