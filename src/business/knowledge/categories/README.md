# categories

Business rapor ve KPI’ların bağlandığı kategori tanımları.

- `CategoryDefinition.ts` — tip sözleşmesi
- `CategoryRegistry.ts` — statik kategori listesi (fonksiyonel + sektörel)

Yeni kategori eklemek için `CategoryDefinition` tipine kimlik ekleyip `CategoryRegistry` listesine kayıt yazın.
