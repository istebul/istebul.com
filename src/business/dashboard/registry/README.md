# registry

- `DashboardRegistry` → `DASHBOARD_PROFILE_REGISTRY`
- `WidgetRegistry` → `DASHBOARD_WIDGET_REGISTRY`
- `LayoutRegistry` → `DASHBOARD_LAYOUT_REGISTRY`
- `ThemeRegistry` → `DASHBOARD_THEME_REGISTRY`
